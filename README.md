# Ходилка по Фаэруну

Браузерная карта для ведения D&D: отряд ходит по азимуту, туман войны, метки и отдельный экран игроков для телевизора.
Работает статикой на GitHub Pages, ничего устанавливать не нужно.

- `index.html` — экран мастера.
- `player.html` — экран игроков (открывается кнопкой с экрана мастера).

## Как играть

1. Откройте экран мастера и нажмите **«Открыть экран игроков ↗»**. В Chrome/Edge окно само откроется на втором мониторе, если дать доступ к экранам. Иначе перетащите его на телевизор.
2. На экране игроков нажмите **F** или сделайте двойной клик — полный экран.
3. Выберите направление на компасе (или Numpad, или инструментом 🧭 по карте), задайте расстояние (по умолчанию 6 км) и нажмите **Enter**.

Экраны связаны через `BroadcastChannel`, поэтому оба окна должны быть открыты в одном браузере на одном компьютере (ноутбук + телевизор по HDMI как второй монитор).

## Управление (мастер)

| Клавиша | Действие |
|---|---|
| Enter | сделать ход |
| Numpad 1–9 | направление; Shift+Numpad — сразу шаг |
| Ctrl+Z | отменить ход |
| C | к отряду |
| V / D / G / M / W / R / H / L / P | обзор / направление / идти к точке / переставить отряд / метка / открыть туман / скрыть туман / линейка / пинг |
| Shift+клик | пинг (видят оба экрана) |
| колесо, правая/средняя кнопка, пробел+перетаскивание | масштаб и перемещение карты |
| Tab | спрятать панель |

Экран игроков: колесо — масштаб, перетаскивание — перемещение, клик — пинг (виден мастеру), F — полный экран, C — к отряду.
Режимы камеры игроков: «следить за отрядом», «повторять мой вид», «свободно». Розовая рамка на экране мастера показывает, что сейчас видят игроки.

## Сохранение

Всё (положение, след, метки, туман) хранится в `localStorage` браузера и переживает перезагрузку.
Для переноса на другой компьютер или бэкапа есть **Экспорт/Импорт** в JSON.

## Масштаб

По шкале на карте 360 миль = 453 px исходного изображения, т.е. ≈ 1.279 км на пиксель (одинаково для Фаэруна, Кара-Тура и Мацтики на этой сборной карте). Значение можно поправить в настройках.

## Вид карты

Карта рисуется через WebGL (Chrome/Edge/Firefox с аппаратным ускорением), стиль — в духе Battle Brothers:

- **Ползунок «Рисованная ↔ Оригинал»** — плавно смешивает перерисованную карту с исходной картинкой.
- **Рисованная карта** строится по разметке: тёмная оливковая трава, почти чёрные леса (при приближении — отдельные деревья), серые скалистые горы со снежными вершинами (пики проявляются при приближении), охристые пустыни с дюнами, рыжие болота с лужами, бирюзовое море с песчаной кромкой и пеной, реки, сельские дороги, Подземье.
- **Названия** берутся с оригинала (маска букв) и рисуются светлыми буквами с тенью; появляются при приближении. Видны игрокам только в открытых областях.
- **Поселения** — маленькие рисованные городки, замки и деревни на месте значков оригинала.
- **Сезоны** — весна / лето / осень / зима с плавным переходом.
- **Облака** — плывут по карте и отбрасывают тени.
- **Туман войны** — клубящаяся дымка, края открытых областей рваные.
- **Качество** — «Низкое» для слабых видеокарт. Без WebGL показывается обычная картинка.

### Разметка

```
pip install numpy opencv-python-headless pillow
python3 tools/classify.py assets/faerun-full.jpg data          # местность, реки, дороги → data/t0..t3.png (~4 мин)
python3 tools/labels.py assets/faerun-full.jpg labels          # слой названий → labels/
python3 tools/settlements.py assets/faerun-full.jpg data/settlements.json   # значки поселений
```

## Карта и тайлы

Исходник: `assets/faerun-full.jpg` (11304×4723). Для быстрой загрузки он нарезан на тайлы в `tiles/`.
Если замените карту — перегенерируйте тайлы (нужен Python + Pillow):

```
python3 tools/make_tiles.py assets/faerun-full.jpg tiles
```

## Запуск локально

Модули ES не работают с `file://`, нужен любой статический сервер:

```
python3 -m http.server 8000
```

и открыть http://localhost:8000.

## Обзор, разведка и противники

- **Обзор отряда** по умолчанию 3 км: при каждом ходе открывается полоса такой ширины вдоль пути.
- **Разведка** (кнопка 🔭 или S) открывает круг вокруг отряда (радиус 5 км, диаметр 10) и гарантированно находит противников в нём. По умолчанию тратит ход.
- **Ждать ход** (⏳ или Z): отряд стоит, противники ходят.
- Туман хранится как список фигур и рисуется видеокартой с точностью экрана на любом зуме; старый сохранённый туман стал подложкой.

### Вражеские отряды (панель «Противники», можно выключить)

- Живут только в круге 100 км вокруг отряда игроков; вышли за круг — исчезают, вместо них появляются новые (не ближе 15 км). Количество настраивается.
- Бродят по 3 км за ход, обходя воду; видят на 5 км. Отряд игроков в зоне обзора замечают с личным шансом каждого отряда, потом решают, интересно ли; иногда проводят разведку (радиус 5 км).
- Заинтересовавшиеся идут на перехват по 3–7 км за ход. Если игроки ушли дальше 10 км, противник теряет интерес.
- Игроки видят противника, только когда заметили его: в своём обзоре 3 км (с шансом, по всему пути хода) или разведкой. Замеченных видят, пока те ближе 10 км; дальше — теряют из виду.
- Мастер видит всех: круги обзора, круг симуляции и сопровождения, стрелки погони, журнал событий; может показать/скрыть отряд игрокам, включить погоню, переименовать, убрать, поставить свой отряд инструментом 👹 (E) и перетащить.
- «Отменить ход» возвращает противников на прежние места.

## Места и энциклопедия

- `data/places.json` — 297 поселений Фаэруна (столицы, города, порты, крепости, руины, храмы) из проекта
  [LoreMaps](https://github.com/loremaps/LoreMaps), координаты пересчитаны на нашу карту
  (`tools/import_loremaps.py`; их карта — та же картинка Pocket Plane Group, сдвиг найден сопоставлением SIFT).
- Значки поселений (`data/settlements.json`) оставлены только для мест из этого списка.
- Карточка места подгружает вводный текст статьи с [Forgotten Realms Wiki](https://forgottenrealms.fandom.com)
  (тексты вики — CC BY-SA), его можно показать игрокам на телевизоре.
- Шрифты Alegreya SC, Alegreya и Cinzel (SIL Open Font License) лежат в `assets/fonts/`.
